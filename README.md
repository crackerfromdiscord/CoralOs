# CoralOS

CoralOS is a desktop experience built on top of Ubuntu 24.04 LTS (GNOME).

## Components

| Path | What it is |
| --- | --- |
| [`ui/welcome-screen`](ui/welcome-screen) | The CoralOS welcome screen: avatar, progress ring and "Welcome, {name}" shown while the desktop session loads after login. See [docs/login-screen.md](docs/login-screen.md). |
